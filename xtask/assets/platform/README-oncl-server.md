# oncl-server {{VERSION}} ({{FLAVOR}})

`oncl-server` это HTTP-сервис OpenNCALayer. Настольная программа для него не нужна, он поставляется
отдельным пакетом. В архиве лежат программа, пример конфигурации и файлы для эксплуатации.
По умолчанию сервис не открывает ни одного сокета: HTTP API выключен, пока оператор не напишет
конфигурацию с закрытым доступом и явно не включит его (`enabled = true` или
`serve --enable-api`). Доверие, автозапуск и автообновление сервис никогда не настраивает.

## Быстрый старт (первый запуск без прослушивания порта)

```sh
oncl-server --version
oncl-server serve --config /etc/oncl-server/server.toml
# disabled: no listener      <- с примером конфигурации (`enabled = false`)
```

Начните с `server.example.toml`: скопируйте его в закрытый каталог оператора и дальше действуйте
по `docs/server.md`. Создайте токен:

```sh
oncl-server token-create --directory /etc/oncl-server --name client.token
# печатает verifier=<64 шестнадцатеричных знака>; поместите его в [[tokens]] файла server.toml
```

Затем включите API на loopback (`oncl-server serve --config ... --enable-api`). Клиентом служит
`oncl --endpoint http://127.0.0.1:13579 --token-file client.token ...` из пакета `oncl`.
Для доступа из локальной сети нужно явно настроить TLS или доверенный обратный прокси.

В архив не входят сертификаты, ключи, пароли, токены и тестовые файлы. Маршрутов шифрования и
расшифрования нет, для них нужна казахстанская ГОСТ-часть. Чтобы обновить сервис, замените
программу и перезапустите его, сам себя он не обновляет.
