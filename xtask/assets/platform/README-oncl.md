# oncl {{VERSION}} ({{FLAVOR}})

`oncl` это командная строка OpenNCALayer: хеширование, подпись, проверка, извлечение, просмотр
содержимого, продление, метки времени, JWS/JWT, вызовы плагинов и пакеты операций. Настольная
программа для неё не нужна. `oncl` не запускает демон, HTTP-сервер или сеанс браузера, ничего не
устанавливает и ничего не пишет вне указанных вами путей. Архив содержит саму программу, а не
установщик, и поставляется отдельно от настольного пакета OpenNCALayer и от `oncl-server`.

## Быстрый старт

Распакуйте архив в любой каталог и запускайте программу оттуда:

```sh
oncl --version
printf abc | oncl hash --algorithm sha256 --input -
# ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
oncl verify --profile cms --input signature.p7s --root nca-root.der
```

Встроенного хранилища доверия нет, доверенные корни передаются через `--root`. Закрытые ключи
берутся из файлов PKCS#12/JKS или из указанного вами считывателя смарт-карт. Пароли читаются
только из файла секрета, доступного одному владельцу, или с терминала, но не из аргументов.
Для подписи нужен ключ `--authorize`, явное подтверждение именно этой операции.

С `--endpoint https://host:13579 --token-file client.token --ca-file ca.pem` те же команды
работают как клиент `oncl-server` (отдельный пакет).

Полное описание лежит в `docs/cli.md` в этом архиве.

## Состав

| Файл | Что это |
|---|---|
| `{{EXE}}` | программа |
| `docs/cli.md` | команды, коды выхода, удалённый режим |
| `THIRD-PARTY.txt` | лицензии сторонних компонентов этой сборки |
| `LICENSE`, `NOTICE` | Apache-2.0 и уведомления |

В архив не входят сертификаты, ключи, токены и тестовые файлы. Команд шифрования и расшифрования
нет, для них нужна казахстанская ГОСТ-часть, которой пока нет.
