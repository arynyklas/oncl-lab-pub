# Фикстуры сайта проекта

Синтетические входы `cargo xtask registry build`: вымышленные порты, индексы обновлений, список релизов, данные ветки `upstream` и сторонние издатели с их ролями. Настоящих данных оригинала здесь нет; реальное имя есть только у бандла ядра `kz.gov.pki.kalkan.xmldsig`, который уже перечислен в коде (`oncl_builtin_accessory::bundles`). Лицензия репозитория (Apache-2.0).

| Путь | Что |
|---|---|
| `plugins/alpha/` | порт в `stable` и `beta`; у оригинала та же версия (`same`) |
| `plugins/gamma/` | порт без индексов; у оригинала другая версия (`changed`) |
| `plugins/hostile/` | порт только в `beta`, бандла нет в фактах (`removed`); все текстовые поля — враждебная разметка и синтаксис шаблонов |
| `updates/v1/{stable,beta}.json` | индексы каналов: отозванные версии, раскатка, плагины на релизе `plugins-20261101`; без подписей |
| `releases.jsonl` | список релизов в формате шага `gh api` workflow: `v0.2.0` со всеми файлами, пререлиз `v0.3.0-beta.1` без файлов macOS, черновик `v0.3.0-beta.2`, тег плагинов, копия пакета издателя `pub-acme-…` |
| `upstream/index.json`, `upstream/latest/facts.json` | история (первое наблюдение и изменение, у изменения недопустимый `path`) и факты манифеста: порты `alpha` и `gamma`, бандл ядра с версией не как у нас, бандл без порта; заметки с враждебным текстом |
| `publishers/acme/` | действующий издатель: `display`, `homepage` и `contact` — враждебная разметка и синтаксис шаблонов; заменяет порт `alpha` (`supersedes`), владелец отозвал `kz.acme.market` 1.1.0 |
| `publishers/olden/` | издатель на покое (`retired`) |
| `publishers/gone/` | отключённый издатель (`revoked`, 2026-10-01) |
| `tuf/v1/metadata/{1,2}.pub-acme.json` | роли `acme`: в версии 1 старый плагин (на сайт не попадает), в версии 2 — `kz.acme.market` (заменяет бандл порта `alpha`; 1.0.0, 1.1.0, бета 1.2.0-beta.1 с раскаткой 50 %; враждебное название, `vcs` и каталог крейта), `kz.acme.sign` (заменяет бандл без порта; 2.1.0 отозвана ролью) и цель с чужим модулем, которую сайт отбрасывает; без подписей |
| `tuf/v1/metadata/1.pub-olden.json`, `1.pub-gone.json` | роли издателя на покое и отключённого (её цели на сайт не попадают); без подписей |

Файлы правятся руками вместе с тестами `xtask::registry` и `xtask/tests/registry_site.rs`, которые на них опираются.
