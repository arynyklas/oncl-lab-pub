# Безопасность

## Как сообщить об уязвимости

Не пишите об уязвимостях в Issues и в чат, они публичные.

Сообщите приватно через GitHub: вкладка **Security**, затем **Report a vulnerability** ([прямая ссылка](https://github.com/arynyklas/OpenNCALayer/security/advisories/new)). Сообщение увидят только мейнтейнеры.

Опишите, что не так, на какой версии и как это воспроизвести. Не прикладывайте настоящие ключи, пароли и сертификаты, достаточно тестовых.

## Что дальше

- На сообщение отвечаем в течение нескольких дней.
- Исправление выходит в новой версии, после чего уязвимость описывается в GitHub Security Advisory.
- Поддерживается только последняя выпущенная версия.
